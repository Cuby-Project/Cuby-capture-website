## 📝 Description

Cuby Capture Website is the web interface component of the Cuby ecosystem, providing a user-friendly way to capture and process Rubik's Cube states. This website integrates with the Cuby Capture API to offer a seamless cube state capture experience.

## 🚀 Getting Started

### 🔧 Prerequisites

- Node.js 16+
- npm or yarn
- Modern web browser

### 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/Cuby-Project/Cuby-capture-website.git
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm run dev
# or
yarn dev
```
